# 五、README.md骨架

```
#🌾 田野物语 · 三韵集

## 项目简介

《田野物语 · 三韵集》是一款基于 JavaFX 开发的农场经营模拟系统。
玩家将在虚拟农场中：

- 种植作物
- 管理天气
- 培育品质
- 建设农场
- 完成收集

打造属于自己的特色庄园。


# 技术栈

|技术|版本|
|-|-|
|Java|17|
|JavaFX|17|
|Maven|3.9+|
|JSON|Jackson|
|JUnit|5|

# 核心特色

## 🌱 作物生命记忆系统

每株高级作物拥有：

- 成长经历
- 天气记录
- 玩家操作记录
- 专属故事


## 🌦 动态天气系统

支持：

- 晴天
- 雨天
- 干旱
- 绿雨

天气影响：

- 成长速度
- 品质概率
- 作物经历


## ⭐ 品质系统


五档品质：


普通

优秀

稀有

史诗

传说


## 🎨 装饰经营系统

装饰不仅用于美化。同时提供：

- 成长BUFF
- 品质BUFF
- 收益BUFF

## 📖 收集系统

包含：

- 作物图鉴
- 装饰图鉴
- 套装收集
```
