# 一、项目简介

## 1.1 项目名称

《田野物语 · 三韵集》(Field Story Farm)


## 1.2 项目介绍

《田野物语 · 三韵集》是一款基于 JavaFX 开发的桌面端农场经营模拟系统。

玩家将在虚拟农场中完成：
- 土地管理
- 作物种植
- 作物成长
- 天气应对
- 品质培养
- 农场建设
- 图鉴收集
等操作，逐步将一片普通土地发展为具有特色的个性化农场。

项目在传统农场模拟玩法基础上，加入：
- 作物生命记忆系统
- 动态天气系统
- 品质进化机制
- 装饰经营反馈系统
- 随机事件系统
增强游戏的策略性、成长感和展示效果。



# 二、项目特色

## 2.1 作物生命记忆系统

不同于传统农场游戏中“作物只是资源”的设计。

本项目会记录作物：
- 种植经历
- 天气变化
- 浇水次数
- 施肥次数
- 品质变化
最终生成独立的成长故事。

例如：一株经历干旱、及时浇水并最终突破品质的小麦，将拥有属于自己的成长记录。


## 2.2 动态天气系统

系统模拟：
- ☀ 晴天
- 🌧 雨天
- 🔥 干旱
- 🌿 绿雨

不同天气会影响：
- 作物成长速度
- 品质概率
- 作物成长经历

玩家需要根据天气调整经营策略。


## 2.3 品质培养系统

作物拥有五种品质：
|品质|倍率|
|普通|×1  |
|优秀|×1.5|
|稀有|×2  |
|史诗|×3  |
|传说|×5  |

玩家可以通过：
- 天气经历
- 浇水
- 施肥
- 装饰BUFF
培养高品质作物。


## 2.4 装饰经营系统

装饰不仅用于美化农场。

不同装饰还会提供：
- 成长速度提升
- 品质概率提升
- 出售价格提升

形成：
种植➡收益➡购买装饰➡提升效率➡培养更高级作物```的经营循环。

# 五、运行方式

## 5.1 环境要求

运行本项目需要：
- JDK 17+
- Maven 3.9+
- JavaFX 17环境


## 5.2 克隆项目

```bash
git clone 项目地址
````

进入项目目录：
```
cd field-story-farm
```


## 5.3 Maven运行

执行：
```
mvn clean javafx:run
```
即可启动游戏。


## 5.4 打包运行

执行：
```
mvn clean package
```

生成项目构建文件。

# 八、AI使用与核对说明

## 8.1 AI使用目的

本项目开发过程中使用AI工具作为辅助工具，主要用于：
- 项目方案讨论
- 架构设计参考
- 代码思路分析
- 文档整理
- Bug排查辅助

AI主要承担：“辅助分析与提高开发效率”的作用。


# 8.2 AI辅助内容

主要包括：

## （1）项目规划辅助

AI用于协助：
- 梳理项目需求
- 优化功能模块划分
- 制定版本开发计划

最终方案由项目成员根据：
- 实际开发周期
- JavaFX能力
- 项目难度
进行调整确认。

## （2）代码设计辅助

AI用于：
- 提供类结构设计建议
- 分析代码组织方式
- 提供算法思路

例如：
- MVC架构设计
- Service层划分
- JSON存档结构

所有代码均由成员理解后实现。

## （3）问题分析辅助

开发过程中遇到：
- 编译错误
- 逻辑问题
- 架构问题
时，通过AI辅助分析可能原因。

最终解决方案由成员：
- 查看源码
- 调试运行
- 测试验证
后确定。


# 8.3 AI内容核对方式

所有AI生成或参考内容均经过人工核验：

包括：

## 功能核验
确认：
- 是否符合项目需求
- 是否能够实际运行

## 代码核验
确认：
- 是否理解代码逻辑
- 是否符合项目架构
- 是否能够独立维护

## 测试核验
通过：
- 实际运行
- 单元测试
- 功能测试

验证正确性。


# 8.4 AI使用原则
项目遵循：
> AI辅助开发，而非替代开发。

团队成员保证：
- 理解项目代码
- 掌握核心设计
- 能够解释实现原理
- 能够独立维护系统
